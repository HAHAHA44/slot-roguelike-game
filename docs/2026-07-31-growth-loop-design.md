## 为什么要做这一轮

M1 结束时的实际状态：cascade 跑通、6 张碎片、UI 光效齐备，但

1. 碎片池出生即定型，整局**只能删不能加**——没有任何成长通道
2. 当年生肖 / 本命年 / 奖励格**只喂 UI 和日志**，对结算零影响
3. 六维与开局 Buff 是**死数据**，`AttributeService` 自己注释着"具体加成留到后续"
4. `report.total_score` 算完**只进日志**，不换任何东西
5. 因此第 3 年和第 70 年的 cascade 期望值**完全一样**

dev-plan 给 M1 挂的质量门是「自玩 10 次，问我想看下一年吗」。以上述形态，答案结构性地是
"不想"——不是特效不够，是**下一年没有任何东西会不一样**。本轮设计补的就是这条闭环。

## 一、年循环（决策后的完整形态）

```
每一年：
  1. 三选一抽碎片      投注池 = 当前阶段碎片，双重加权，可免费跳过；要就得弃一张
  2. 行囊调阵          看明年的年度规则，把行囊与命盘的碎片对换（免费，不限次）
  3. 投盘 + cascade    12 张洗牌上盘 → min-score-first 结算 → 年收益（≈5.4 秒动画）
  4. 道具商店          年收益按"几个阶段门槛"计价，买乘区道具或跳过
  5. 年末事件          流水年滚一行金句（不阻塞）／转折年弹窗做选择（约 15–25%）
  6. 年龄 +1，属性漂移

每 12 年（= 一个人生阶段）：
  · 阶段门槛考核：年收益未达标 → 精神力大跌 → 后续转折年更频繁更凶险
  · 满星碎片 → 进化为传承物，带进下一阶段
  · 其余碎片全部清空，命盘从传承物 + 新一轮 12 次抽取重新长起来
```

**时间预算**（cascade 5.4 秒为实测，其余按熟练玩家估）：每年约 17 秒 × 85 年 ≈ 24 分钟，
加 17 次转折年弹窗 ≈ **28 分钟**，压在 fun-axes 度量表的 15–30 分钟上限内，**无余量**。
新手逐字读卡会显著超出；寿命抽到 110 的局约 36 分钟。这是已知代价，不是疏漏。

## 二、23 条决策

### 经济与容器

| # | 决策 | 关键理由 |
|---|---|---|
| 1 | 方向 = 补成长闭环，非铺内容量 | 铺量只是让 12 个一样的年份更花哨 |
| 2 | 年收益双层：可花费 + 阶段末被考核 | 一个数同时当资源和成绩 |
| 3 | **命盘恒 12**，另设行囊 6 格 | 见 ADR-0001 |
| 4 | 行囊用途 = 按当年生肖调阵 | 让"最优 12 张"逐年变化，否则配一次装就锁死 |
| 7 | **相对计价**：阶段门槛兼任计价基准 | 只调一条曲线；购买力恒定而绝对数字可爆炸 |
| 13 | 商店卖**道具**（每年），碎片走三选一 | 骨架靠际遇，乘区靠经营；两套资源两个节奏 |
| 17 | 行囊 = 材料区与备选区**共用** | 一格两用，白赚"留着合还是拿去用"的取舍 |
| 19 | **二元制**：只有碎片与道具，"卡片"是口语 | 拒绝第三套规则；道具可当合成材料，跨系统耦合 |

### 成长与合成

| # | 决策 | 关键理由 |
|---|---|---|
| 5 | **12 生肖各携一条年度结算规则** | 见 ADR-0002 |
| 6 | 膨胀引擎 = 升星 + 传承（碎片需实例化） | 命盘封顶，只能靠单张变强 |
| 15 | 三选一带"都不要"，要就弃一张 | 定编制、养成、时间预算三者唯一的共解 |
| 18→ | **碎片按阶段分池**，满星者传承 | 见 ADR-0003 |
| 20 | 三张→二星，两个二星（共六张）→满星 | 达成率约 40%，一生约 3 次传承，稀缺才郑重 |
| 21 | 传承物**永久**且可**链式进化** | 梦幻局叙事：一生专精一件事 |
| 22 | **领域加权** + 链长封顶三环 | 把连中三次从 6.4% 拉到约 15%，内容量可控 |
| 23 | 异名配方 **v1 不做**，只留字段 | 唯一内容量不封顶的系统，排在第三优先 |

**投注池的两重加权**：① 已持有的同名碎片权重加倍（凑星可行）；② 持有某领域传承物则该领域
碎片权重上升（链条可延续）。三张候选建议构成为 **2 张加权 + 1 张纯随机**，纯随机位保留惊喜
与转型机会。

### 紧张感与人物

| # | 决策 | 关键理由 |
|---|---|---|
| 8 | 考核没过 → **扣精神力** → 事件权重 | 紧张感只走"精神力 + 事件"一条管道，不撞硬约束 |
| 9 | **快慢分层**：便宜决策每年，昂贵的低频 | 85 年 × 全套决策装不进 30 分钟 |
| 10 | 六维各接一类 cascade 效果 | 前四维的帐篷曲线 = 壮年是强度巅峰，免费拿到 |
| 11 | Buff/Debuff = **出生时一次性**改开局参数 | 语义就是出生条件；且是 M6 转世的天然接口 |
| 12 | **双层事件**：流水年金句 + 转折年弹窗 | 叙事密度零成本拿到，转折稀缺才被认真读 |

**六维接线明细**：力量→"加自身分"类效果；智力→同生肖联动；敏捷→邻接联动；耐力→全体基础分；
精神力→转折年密度 + 恶性/致死权重；运气→投注池与商店的稀有度权重。属性仍随机漂移，
玩家不能选方向——build 方向有相当部分是"投胎 + 天意"，只能顺势而为。

## 三、两条待你圈改的默认值

拷问未覆盖，我按前述决策推出建议值，直接在本文改即可：

**① 阶段考核用哪个数**：建议用该阶段**最后一年**的年收益对门槛，而非 12 年累计。
累计会奖励"活得久"，最后一年才反映 build 强度，且命盘在阶段末最满，语义上就是"这十二年练出的成果"。

**② 行囊换阵是否免费**：建议**免费、不限次，但只在投盘前的调阵阶段可操作**。
6 格容量本身已是约束，再加次数限制是双重约束，只会增加操作摩擦；投盘后禁止改动，
否则玩家能在看到 cascade 结果后反悔。

23 条决策**全部实装**，两条待圈改的默认值按建议值落地（阶段考核用最后一年；行囊换阵免费不限次）。
下面只记**没做到的**和**做法与本文不同的**。

### 内容量：够玩，但没铺到目标数

| 内容 | 本文目标 | 实际 | 差在哪 |
|---|---|---|---|
| 阶段碎片 | ~84 | **84**（7 阶段 × 12） | 达标 |
| 传承物 | 9–12 | **15**（5 领域 × 3 环） | 超出，五条领域线都做全了 |
| 年度规则 | 12 | **12** | 达标 |
| 道具 | ~20 | **20** | 达标 |
| 转折年事件 | ~70 | **46** | **少 24 个**：24 通用 + 21 阶段专属 + 3 本命年 |
| 流水年金句 | ~200 | **147**（7 阶段 × 三档 × 7 条） | **少 53 条** |

事件与金句偏少是取舍：优先把每一条写到符合 fun-axes 的规格（正文 ≤2 句、选项 ≤1 句、
要画面不要信息量），而不是凑数。补量时按 `scripts/dev/content_tables.gd` 的表格式追加即可，
**但请直接写 `.tres`**——生成器已经用完，重跑会覆盖手改。

### 与本文写法不同的一处

**道具没有做 PRD 里那四个 `ScriptableEffect` hook**（`on_year_start` / `on_settle` /
`on_event` / `on_death`），而是直接用具名的乘区字段（`settle_percent` / `zodiac_percent` / …）
折进 `YearModifiers`。理由：Q13 定的道具职责是「今年整盘按什么倍率算」，它没有触发时机、
也没有目标，套 effect 那层壳只会多一层空转。四个 hook 里只有 `on_settle` 有实际语义，
而那正是现在这组字段做的事。要做「死亡瞬间触发」之类的效果时再加不迟。

### 仍然没做的（本文本来就没规划，此处只作交接）

- **关系系统**（`RelationshipService` 文件在，主流程没调）
- **转世闭环**（`KarmaService` 在累加 `karma_in_run`，但死亡后不落盘、下一世不读它）
- **暮年 endless 专属内容**（暮年现在只是第 7 个普通阶段，没有专属 token 联动或「传承」事件）
- **异名配方合成**（Q23 明确 v1 不做；`domain` 字段已备好，v2 直接填内容）

### 一次实测（`--steps=34` 的一条人生）

年 0 收益约 100 → 年 33 收益 1074，最高连击 4，34 岁时命盘 8 张（含一件传承物「小有积蓄」），
阶段考核 1074/1080 擦线未过。曲线是对的形状，**但配平还没调过**——
这是下一步该做的事，不是这一轮的产出。

### 顺手修掉的一个真 bug

`RunScreen._first_of()` 原本在 lambda 里写 `done = true`。GDScript 的 lambda **按值捕获**
局部变量，所以外层的 `done` 永远是 `false`，`while not done` 会死循环——
玩家点任何模态都会卡住。同步路径（测试与 autoplay 走的那条）不经过它，
312 个测试全绿也照样漏掉。现已改用数组当可变容器，并补了两条走交互路径的回归测试。

## 已知风险

| 风险 | 触发条件 | 对策 |
|---|---|---|
| 时间预算无余量（28/30 分钟） | 新手实测超 40 分钟 | 压缩三选一与商店的交互步数，**不动 cascade 节奏**（P1 是宪法） |
| 84 张碎片的写作量拖垮排期 | S2 之后内容进度停滞 | 先做 3 个阶段（童年/少年/青年）验证形态，再铺其余 |
| 传承链多数玩家看不到 | 实测走完三环 < 10% | 上调领域加权系数，而非降低满星门槛（门槛降了会让传承变廉价） |
| 合成让命盘过稀 | 满星局的年收益反而低于摊大饼局 | 满星强度下限 = 补足五格凡庸的损失，这是可计算的锚点 |
| 系统数量压过 cascade | S5 之后玩家说不清分数为什么高 | 每个新系统必须在 UI 上可追溯到具体数字；追溯不了的砍掉 |
