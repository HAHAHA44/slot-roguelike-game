# Reelbound — 爽感设计语言（A 路线）

**日期**：2026-05-18
**前置**：`2026-05-17-life-sim-prd.md`
**决策**：玩家爽感主轴 = **连锁感（cascade）**；次主 = **紧张感（精神力 / 死亡轮盘）**

> 本文是 A 路线的"设计语言宪法"。所有 token / 事件 / UI / 音效设计必须服务这两条轴，违反就是 bug。

## 设计原则

### P1 cascade 是最高优先级的视听事件
- 每个 token 结算之间有微停顿（300–500ms），玩家必须看见多米诺
- 严禁"瞬时结算然后弹个总分"
- 严禁任何打断 cascade 节奏的弹窗 / 教学 / 提示

### P2 数字必须能炸破天
- 早期 3 位年收益 → 中期 5 位 → endless 7 位+
- 物品 modifier 用乘法不用加法
- token effect 必须可堆叠 + 联动倍增
- 不允许任何"分数封顶"逻辑

### P3 紧张感服务于 cascade 的赌注感
- 精神力存在的意义是让"今年炸得够不够大"有赌注
- 高精神 = 安全的良性事件池（cascade 收益 → token / 物品）
- 低精神 = 死亡轮盘开启（cascade 没炸大就死）
- 紧张感 **不允许独立成轴** —— 它是 cascade 的赌注放大器

### P4 叙事和滚雪球是隐性副产品
- 不投资严肃叙事系统（CK3 风长事件链 = 反模式）
- 不投资数字优化系统（让 token 设计自然滚雪球，别加"凋零机制"）
- 文案只需"金句感"，不需"段落感"

## Cascade 视听语言

### 节奏
- token 结算间隔 300ms（默认）
- 触发联动时拉长到 500ms
- 最后一个 token 结算前 700ms 慢镜头 + 镜头微推

### 视觉
- token `current_score` 变化用数字弹跳 + 颜色等级
  - 0–99 白 / 100–999 黄 / 1k–9k 橙 / 10k+ 红 / 100k+ 紫 / 1M+ 金虹
- 联动连线高亮：同生肖红线 / 邻接蓝线 / 同类绿线
- 连线粗度随 chain count 增加
- 屏幕震动随当前 token current_score 等级缩放

### 听觉
- 每多触发一次联动，主音效音高升半音（max 12 半音 = 一个八度）
- 数字突破等级时叠加"达成"音效（金币声 / 编钟 / 龙吟）
- 慢镜头时降低 BGM 音量 50%

### 连击 banner
| chain count | banner |
|---|---|
| 3 | 开门红 |
| 5 | 福星高照 |
| 7 | 鸿运当头 |
| 12（全场触发） | 天命所归 |

## 紧张感视听语言

### 精神力可视化
- 环形精神条围绕生肖盘外圈
- 50+ 蓝白 / 30–50 黄 / 0–30 血红 + 屏幕边缘暗角脉动

### 死亡概率外露
- 年末事件抽取前显示 "良性 X% / 中性 Y% / 恶性 Z%（含死亡 W%）"
- 让玩家做**明牌**风险评估，不要黑箱

### 本命年高风险高回报
- 本命年精神力变化幅度 ×2
- 本命年事件池更极端（大喜大悲）
- 本命年 cascade 收益 ×1.5

### 寿命倒计时
- 暮年阶段（72+）显示 "你已 X 岁（寿命 Y）"
- 寿命剩 ≤ 3 年时，年末加一张"善终事件"机会牌

## Token 设计准则（服务 cascade）

### 三类必备 effect
1. **加自身分**：base_score += N（基础积分块）
2. **改邻居 / 同生肖 / 同类分**：trigger 时给目标 +N 或 ×N
3. **联动触发**：满足条件时触发额外 effect 链

### 设计禁区
- ❌ 一次性使用的 token（破坏"全场都在炸"的节奏）
- ❌ 完全独立的 token（没有联动 = 无聊）
- ❌ "扣分"惩罚 token（除非是高回报赌博 token）

### 数量目标
- v1 验骨架：~15 个 token，覆盖 4–5 种联动模式
- v2 铺量：~50 个 token，每生肖 ~4 个 + 杂项 ~10 个
- endless：~100+ token，提供"破游戏" build 空间

## 事件设计准则（服务紧张感）

### 三档 sanity_weights
- **良性**（机遇 / 物品 / 关系 / 属性）：高精神 5× / 中段 1× / 低段 0.2×
- **中性**（小起小落 / 选择题）：均匀分布
- **恶性**（病灾 / 破财 / 死亡）：低精神 5× / 中段 1× / 高段 0.1×
- **死亡**（lethal）：只在低段（如 ≤ 30）非零

### 文案准则
- 一个事件 ≤ 2 句正文 + ≤ 4 个选项（每选项 ≤ 1 句）
- 金句感 > 信息量："你在街角捡到一张皱巴巴的钞票" 而非 "你获得 100 元"
- 不写"你..."长描述，写画面

## 反模式（A 路线明令禁止）

- ❌ 严肃叙事系统（CK3 风长事件链 / 多回合追踪）
- ❌ 实时压力（任何形式的时间限制 / 倒计时操作）
- ❌ 网格放置策略（玩家手动摆 token 优化布局 → 偏离 cascade 主线，退化回 slot）
- ❌ 平衡性"凋零"（让旧 token 变弱 → 破坏滚雪球）
- ❌ 分数封顶 / 等级封顶
- ❌ 跨年追踪的复杂状态（每年应尽可能独立结算）

## 度量（M1 后必须开始记录）

| 指标 | 目标 |
|---|---|
| 平均单局时长 | 15–30 分钟 |
| 单年 cascade 时长 | 8–15 秒 |
| 单局最高连击 | ≥ 7 |
| 单局最高年收益 | base 的 50× |
| 死亡事件触发率（低精神段） | ≥ 30% |
| 死亡事件触发率（全程） | < 10% |
| "还想再来一把"率（自测） | > 60% |

## 与 PRD 的关系

PRD 描述**这是什么游戏**；本文描述**这游戏要让玩家感觉到什么**。
两者冲突时，本文优先 —— 因为 PRD 是机制，本文是机制的目的。
